# 💰 Мои траты — Telegram-бот для учёта личных финансов

Бот для общего бюджета пары: пишешь ему трату текстом или голосом — он сам
определяет сумму, валюту и категорию, а по кнопке показывает, куда уходят деньги.

## Что умеет

- **Запись трат текстом:** `500 кофе`, `150k донг обед`, `1000 руб такси`
- **Запись голосом:** «кофе пять долларов, такси десять и обед двенадцать» → три траты
- **Три валюты:** доллары (по умолчанию, USDT = $), вьетнамские донги, рубли
- **8 категорий**, которые бот угадывает по словам:
  🍔 Еда · 🚕 Транспорт · 🏠 Жильё · 📱 Подписки · 🎉 Развлечения · 💅 Красота · 🏋️ Спорт · 📦 Другое.
  Если не угадал — показывает кнопки выбора.
- **Отчёты** за сегодня, неделю и месяц: итог по каждой валюте, разбивка по категориям
  и общий итог в долларах по текущему курсу
- **Таблица Excel** со всеми тратами прямо в Telegram (`/export`)
- **Общий доступ для двоих:** чужим бот не отвечает, новых людей владелец пускает кнопкой
- **Работает 24/7** на бесплатном хостинге PythonAnywhere
- **Сам напоминает** о продлении бесплатного хостинга

## Пример отчёта

```
📊 Траты за октябрь 2026

💵 Доллары: $735
   🏠 Жильё: $700 (95%)
   🏋️ Спорт: $30 (4%)
   🍔 Еда: $5 (1%)

🇻🇳 Донги: 800 000 ₫
   💅 Красота: 500 000 ₫ (62%)
   🍔 Еда: 300 000 ₫ (38%)

💰 Всего ≈ $766 (всё в долларах по курсу)
```

## Команды

| Команда | Что делает |
|---|---|
| 📅 Сегодня / `/today` | траты за сегодня |
| 📊 Неделя / `/week` | за последние 7 дней |
| 🗓 Месяц / `/report` | за текущий месяц |
| `/export` | вся таблица файлом Excel |
| `/undo` | удалить свою последнюю трату |
| `/reset` | стереть всё и начать с нуля (только владелец, с копией) |

## Как устроено

| Файл | Зачем |
|---|---|
| `bot.py` | вся логика: разбор трат, категории, валюты, отчёты, голос |
| `flask_app.py` | приём сообщений от Telegram на хостинге (webhook) |
| `run_local.py` | запуск на своём компьютере для проверки |
| `deploy.py` | выкладывает новую версию на PythonAnywhere |
| `remind.py` | напоминание о продлении хостинга |

Технологии: Python, Telegram Bot API, Flask, CSV-таблица для хранения,
[Groq](https://console.groq.com) (Whisper) для распознавания голоса,
[open.er-api.com](https://open.er-api.com) для курсов валют. Всё бесплатно.

## Как запустить свою копию

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.
2. Получи бесплатный ключ на [console.groq.com](https://console.groq.com) (нужен для голосовых).
3. Скопируй `.env.example` в `.env` и впиши туда токен и ключ.
4. Установи зависимости и запусти:
   ```bash
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   .venv/bin/python run_local.py
   ```
5. Напиши боту `/start` — первый написавший становится владельцем.

Для работы 24/7 — бесплатный аккаунт на [PythonAnywhere](https://www.pythonanywhere.com),
файл `.pythonanywhere` с `PA_USER=` и `PA_TOKEN=` и команда `.venv/bin/python deploy.py --data`.
