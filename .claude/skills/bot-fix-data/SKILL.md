# Правка трат на хостинге

Живые данные только на хостинге. Локальный `expenses.csv` не трогать и не выкладывать (`deploy.py --data` — запрещено).

1. Найди записи: `.venv/bin/python hosting.py today` или `.venv/bin/python hosting.py last 20`.
   У каждой трат есть id (первая колонка).
2. Если непонятно, какая запись лишняя (две одинаковые) — удаляй **более позднюю**: первую бот записал,
   просто ответ не дошёл. Если сомневаешься, что это дубль, а не две траты — спроси владельца.
3. Правка (копия до правки сохраняется в `backups/` автоматически):
   - удалить: `.venv/bin/python hosting.py delete ID [ID…]`
   - поправить: `.venv/bin/python hosting.py set ID amount=2500000 category=Транспорт`
     (поля: amount, currency = USD/VND/RUB, category — из `CATEGORIES`, description)
4. Проверь результат той же командой `today`/`last`.
5. Ответ владельцу: что было → что стало, и «нажмите 📅 Сегодня или 🗓 Месяц, чтобы проверить».
