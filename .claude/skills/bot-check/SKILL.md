# Проверка бота

1. `.venv/bin/python hosting.py status` — сайт должен ответить «Бот работает ✅», застрявших сообщений 0.
2. `.venv/bin/python hosting.py today` — траты за сегодня (время по Вьетнаму).
3. Если бот молчал — `.venv/bin/python hosting.py log 30`:
   - «Связь мигнула (ProxyError)» — сбой бесплатного хостинга; трата скорее всего записана, просто ответ не дошёл.
   - Traceback с ошибкой в `bot.py` — это баг: чини через скилл `bot-fix-phrase` или как обычную правку.
   - Застрявшие сообщения > 0 и ошибка Telegram — проверь webhook: `.venv/bin/python deploy.py`.
4. Ответ владельцу таблицей: время · сумма · категория · что. Внизу итог по каждой валюте отдельно.
   Без технических слов.
