# Бот неправильно понял фразу

1. **Узнай точный текст.** Со скриншота — что написал владелец и что ответил бот. Для голосовых
   распознанный текст есть в ответе бота («🎤 Услышал: …») или в таблице: `.venv/bin/python hosting.py last 10`.
2. **Сначала тест, потом починка.** Добавь фразу и правильный результат в `CASES` в `check.py`,
   запусти `.venv/bin/python check.py` — новый тест должен упасть.
3. **Почини разбор** в `bot.py`: `parse_expense` (сумма, валюта), `split_expenses` / `_split_by_numbers` /
   `_apply_quantities` (несколько трат, «по», «за»), `KEYWORDS` (категория; ключ — начало слова, длинные выигрывают).
   Не меняй порядок `CATEGORIES`.
4. `.venv/bin/python check.py` → «✅ всё ок». Старые случаи ломать нельзя.
5. **Выложи:** `.venv/bin/python deploy.py` (БЕЗ `--data`).
6. **Почини данные**, если ошибочная запись уже в таблице — скилл `bot-fix-data`.
7. Строка в `NOTES.md` (раздел «Что сделано», с датой), коммит и `git push`.
8. Ответ владельцу: что было не так (одной фразой), что теперь будет записано, как проверить.

## Приёмы, которые уже сработали
- Голос приходит без запятых → резать по числам (`_split_by_numbers`), валюту оставлять при своей сумме.
- «2 тыс. руб» — точка после «тыс/руб/дол/млн» не разделитель.
- «1,5 латте» — делить только по «, » (с пробелом).
- Слишком общие ключевые слова («дом») ловят лишнее — лучше без них.
