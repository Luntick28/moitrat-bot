# AGENTS.md — бот «Мои траты» (@moitrat_bot)

## Зачем и для кого
Telegram-бот для общего бюджета пары (Volodya + девушка), живут во Вьетнаме.
Пишут трату текстом или голосом («кофе 5», «еда 50 жильё 700») — бот записывает,
по кнопкам показывает отчёты. Владелец — не программист: объяснять ему по-русски, просто.

## Запуск и проверка
- Проверить, что разбор трат не сломан: `.venv/bin/python check.py` → «✅ всё ок». Запускать после любой правки `bot.py`.
- Новая фраза, на которой бот ошибся → сначала добавить её в `CASES` в `check.py`, потом чинить.
- Выложить на хостинг: `.venv/bin/python deploy.py` (заливает код, перезапускает, ставит webhook).
- Локально (только для отладки, снимает webhook!): `.venv/bin/python run_local.py`, потом обязательно снова `deploy.py`.

## Нельзя
- `deploy.py --data` — затрёт живые траты на хостинге локальной копией.
- Менять порядок `CATEGORIES` — номер категории зашит в кнопки (`cat:<id>:<номер>`). Новые категории только в конец.
- Коммитить `.env`, `.pythonanywhere`, `expenses.csv`, `allowed_users.txt` (токены и личные траты; репозиторий публичный).
- Подключать платные сервисы и просить данные карты, не спросив владельца.

## Где живёт
- Хостинг PythonAnywhere, аккаунт `proseller`, Python 3.10 (локально 3.13 — не использовать новый синтаксис).
- Живые данные — только на хостинге: `/home/proseller/moitrat/expenses.csv`. Читать/править через PA API
  (ключ в `.pythonanywhere`), перед правкой сохранить копию.
- Логи: `/var/log/proseller.pythonanywhere.com.error.log` и `.server.log`.
- Часовой пояс отчётов — `TIMEZONE` в `.env` (Asia/Ho_Chi_Minh).

## Грабли, на которые уже наступали
- Бесплатный PA ходит в интернет через прокси, тот иногда отдаёт 503 на минуту-две: трата записана,
  а ответ не дошёл → человек шлёт ещё раз → дубль. Поэтому `_post` повторяет запросы, а одинаковая
  трата за 10 минут даёт кнопку «🗑 Удалить повтор». Кодом до конца не лечится — только платный тариф.
- Голос (Groq Whisper) часто приходит без запятых → `split_expenses` режет по числам.
- «две по 22» = 44, «за 2000» — цена; «тыс/млн/k» — множители; «2 тыс. руб» не резать по точке.
- Бесплатный сайт PA надо продлевать (первый срок до 20.11.2026); бот сам напоминает владельцу (`remind.py`),
  проверка идёт при входящих сообщениях — расписание на бесплатном тарифе недоступно.
